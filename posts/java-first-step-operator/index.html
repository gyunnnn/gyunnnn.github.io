김영한의 자바 입문 - 연산자

2026-11-06·2분 읽기

연산자

  • 연산자(operator): 연산 기호
    • 예: +, -
  • 피연산자(operand): 연산 대상
    • 예: 3, 5, a, b, "Hello, World!"

종류

  • 산술 연산자
    • +, -, *, /, %
  • 증감 연산자
    • ++, --
  • 비교 연산자
    • ==, !=, <, >, <=, >=
  • 논리 연산자
    • &&, ||, !
  • 대입 연산자
    • =, +=, -=, *=, %=
  • 삼항 연산자
    • ? :

문자열 더하기

  • Java에서 위와같은 문자열 연산이 성립하는 이유
    • Java 언어 명세(JLS) 에 따르면, + 연산자의 피연산자 중 하나라도 String 이면, 그 + 는 산술 덧셈이 아니라 문자열 연결(string concatenation)로 동작한다고 정의하고 있다.

연산자 우선순위

  • 연산자 우선순위는 기초 수학과 동일하며, 변경하기 위해서는 괄호 ()를 사용한다.
  • 실무에서는 괄호 ()를 사용하여 계산 순서를 명확하고 단순하게 하는 것이 좋다.
  • 아래 순서는 외울 필요가 없으며 필요한 경우 찾아보면 된다.
  1. 괄호 ()
  2. 단항 연산자 (예: ++, --, !, ~, new, (type))
  3. 산술 연산자 (예: *, /, % 우선, 이후 +, -)
  4. Shift 연산자 (예: <<, >>, >>>)
  5. 비교 연산자 (예: <, <=, >, >=, instanceof)
  6. 등식 연산자 (예: ==, !=)
  7. 비트 연산자 (예: &, ^, |)
  8. 논리 연산자 (예: &&, ||)
  9. 삼항 연산자 (예: ? :)
  10. 대입 연산자 (예: =, +=, -=, *=, %= 등)

증감 연산자

전위, 후위 증감연산자

  • ++a
    • 증감 연산자를 피연산자 앞에 둘 수 있다.
    • 전위(Prefix) 증감 연산자라고 한다.
    • 증감 연산이 먼저 수행된 후 나머지 연산을 수행한다.
  • a++
    • 증감 연산자를 피연산자 뒤에 둘 수 있다.
    • 후위(Postfix) 증감 연산자라고 한다.
    • 다른 연산이 먼저 수행된 후 증감 연산을 수행한다.

비교 연산자

문자열 비교

  • 문자열이 같은지 비교할때 ==가 아니라, .equals() 메서드를 사용하여 비교해야 한다.
  • == 사용시 성공할 때도 있지만 실패할 때도 있다.
