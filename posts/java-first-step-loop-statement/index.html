김영한의 자바 입문 - 반복문

2026-11-08·1분 읽기

반복문

while 문

  • 조건식이 참이면 코드 블럭을 실행하고, 거짓이면 while문을 벗어난다.
    • 코드 블록 실행이 끝나면 다시 조건식 검사로 돌아가서 조건식을 검사한다. (무한 반복)

do-while 문

  • while 문과 비슷하지만, 조건에 관계 없이 무조건 한 번은 do 블록 안의 코드를 실행한다.
  • do 블록의 코드를 실행한 뒤, 조건식을 검증한다.
    • 참이면 다시 do 블록의 코드를 실행한다.
    • 거짓이라면 do-while 문을 빠져나온다.

break, continue

  • 반복문에서 사용하는 키워드

  • break

    • 반복문을 즉시 종료 후 탈출한다.

  • continue

    • 반복문 내부의 continue 키워드 이후 부분을 건너 뛰고 다음 반복을 진행한다.
    • while문의 경우 다시 조건식을 판별한 뒤 참이면 블록을 실행하고 거짓이라면 반복문을 탈출한다.

for 문

실행 순서

  1. 초기식 실행, 초기식은 for문 진입 가장 처음에만 1번 실행된다.
  2. 조건식 검증, 참인경우 3.코드를 실행하고, 거짓인 경우 for문을 탈출한다.
  3. 코드를 실행한다.
  4. 증감식을 실행한다.
  5. 다시 2.조건식을 검증한다. 이후 반복
