김영한의 자바 입문 - 배열

2026-11-16·2분 읽기

배열

  • 같은 타입의 변수를 반복해서 선언하고 사용하는 문제를 해결하기 위한 구조

선언과 생성

  • java는 배열을 생성할 때 그 내부 값을 자동으로 초기화한다.
    • new int[5]로 배열을 생성하면, 0이 5개 있는 배열 생성
    • 숫자는 0, boolean은 false, String은 null로 초기화 됨.
  • 참조값 보관
    • new int[5]로 배열을 생성하면, 배열의 크기만큼 메모리를 확보한다.
    • int형 5개 → 4byte * 5 = 20byte 의 메모리를 확보한다.
    • 배열을 생성하고 나면 java는 메모리 어딘가에 있는 이 배열에 접근할 수 있는 주소(참조값)을 반환한다.
    • int[] students에 생성된 배열의 참조값을 보관한다.
    • 이 참조값을 통해 메모리에 있는 배열에 접근하고 그 값을 사용할 수 있다.
    • 배열을 생성하는 new int[5] 자체에는 아무 이름도 없으므로, 생성된 배열에 이름을 붙이고 배열을 생성할 때 반환되는 그 참조값을 해당 이름으로 보관해두는 것이다. 해당 배열의 변수명을 통해 쉽게 접근 가능하다.

사용

  • 변수와 사용법이 비슷하며, [] 사이에 배열의 위치를 나타내는 숫자(index)를 적어준다.
  • 바로 위 내용에서 보았듯이, 배열 변수에는 참조값, 즉 배열의 주소값이 저장되어 있어 변수명을 사용하면 해당 주소값이 접근한 뒤 [] 안의 인덱스값에 위치한 원소에 접근한다.

기본형 vs 참조형

  • java의 변수 데이터 타입을 크게 기본형과 참조형으로 나눌 수 있다.
  • 기본형(Primitive Type)
    • 사용하는 값을 직접 넣을 수 있다.
    • int, long, double, boolean 처럼 변수에 사용할 값을 직접 넣을 수 있는 데이터 타입
  • 참조형(Reference Type)
    • 메모리의 참조값을 넣는다.
    • 데이터에 접근하기 위한 참조(주소)를 저장하는 데이터 타입
    • int[] students와 같은 배열, 객체, 클래스 등
