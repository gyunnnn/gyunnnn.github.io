김영한의 자바 입문 - 메서드

2026-11-19·3분 읽기

메서드

  • 자바에서 함수를 메서드(Method)라고 한다
  • 메서드 ∈ 함수 (함수의 한 종류이다)

메서드 정의 및 사용 예시

  • 메서드는 수학의 함수와 유사한 형태이며, 값을 입력하면 연산을 처리한 후 결과를 반환해준다.

메서드 선언(Method Declaration)

  • public static int add(int a, int b)
    • public: 다른 클래스에서 호출할 수 있는 메서드라는 뜻이다.
    • static: 객체를 생성하지 않고 호출할 수 있는 정적 메서드라는 뜻이다.
    • int: 반환 타입을 정의한다. 메서드 실행 결과를 반환할 때 사용할 타입
    • add: 메서드를 호출할 이름을 정의한다. 이 이름을 통해 메서드를 호출한다.
    • (int a, int b): 메서드 호출 시 전달하는 입력 값을 정의한다. 이 변수들은 메서드 안에서만 사용된다. 이렇게 메서드 선언에 사용되는 변수를 파라미터(parameter), 한글로 매개변수라 한다.

메서드 본문(Method Body)

  • 메서드가 수행하는 코드 블록
  • 메서드 호출 시 본문이 순서대로 실행된다.
  • 메서드 호출부에서 메서드 선언은 알지만, 그 본문은 알지 못한다.
  • 메서드 실행 결과를 반환하려면 return을 사용해야 한다. return 뒤에 반환 결과를 적어준다.
  • 위 예시에서는 sum에 들어있는 값을 반환한다.

메서드 호출 및 용어 정리

인수(Argument)

  • 위 예시에서 "hello", 20 처럼 넘겨주는 값을 Argument, 한글로 인수, 또는 인자 라고 한다.

매개변수(Parameter)

  • 메서드 정의 시 선언한 변수인 String str, int age를 매개변수, 파라미터라고 한다.
  • 메서드 호출 시 인수를 넘기면, 그 인수가 매개변수에 대입된다.

메서드 정의

  • 제어자(Modifier): public, static 등을 제어자라고 한다.
  • 반환 타입(Return Type): 메서드 실행 후 반환하는 데이터의 타입을 지정, 메서드가 값을 반환하지 않는 경우, 없다는 뜻의 void를 사용한다.
    • 모든 메서드는 항상 return을 호출해야 하지만, 반환 타입이 void인 경우, 예외적으로 return을 생략할 수 있다. (자바가 반환타입이 없는 경우 자동으로 return을 마지막줄에 넣어준다.)
      • return문을 만나면 즉시 메서드를 빠져나간다.
    • 반환 타입이 있는 경우 반드시 해당 타입의 값을 반환해야 하며, 조건문을 사용할 때 모든 조건에 대해 반환 타입과 동일한 타입의 값을 반환해야 한다.
  • 메서드 이름(Method Name): 메서드 호출 시 사용할 이름
  • 매개변수(Parameter): 입력 값으로, 메서드 내부에서 사용할 수 있는 변수이다. 옵션이며, 입력값이 필요 없는 메서드는 지정하지 않아도 된다.
    • 매개변수가 없는 메서드는 정의시, 호출시 모두 매개변수를 비워두고 작성한다.
    • 예) printHeader()
  • 메서드 본문(Method Body): 실제 메서드의 코드가 위치한다. 중괄호 {} 사이에 코드를 작성한다.

메서드 호출과 값 전달

  • 자바는 항상 변수의 값을 복사하여 대입한다.
  • 이후 배울 참조형에서는, 참조형 변수에 있는 값인 참조값을 복사한다.

메서드와 형변환

  • 메서드 호출 시 인자와 매개변수의 타입은 일치해야 하며 그렇지 않은 경우 컴파일 오류가 발생한다.
  • 매개변수에 값을 전달할 때도 자동 형변환은 그대로 적용된다.

메서드 오버로딩

  • 이름이 같고 매개변수가 다른 메서드를 여러 개 정의하는 것을 메서드 오버로딩(Overloading)이라고 한다. (overloading → 과적, 물건을 과하게 담았다는 의미)
  • 메서드 이름이 같아도 매개변수의 타입 및 순서가 다르면 오버로딩이 가능하다. 반환 타입은 인정하지 않는다.
  • 메서드 시그니처(method signature)
    • 메서드 시그니처 = 메서드 이름 + 매개변수 타입(순서)
    • 자바에서 메서드를 구분할 수 있는 고유한 식별자나 서명을 뜻한다.
    • 이름과 매개변수 타입(순서 포함)으로 구성되어 있다.
    • 메서드를 구분할 수 있는 기준
    • 메서드 이름이 같아도 시그니처가 다르면 다른 메서드가 된다.
    • 반환 타입은 시그니처에 포함되지 않는다.

메서드명 vs 변수명

  • 변수 이름은 일반적으로 명사를 사용한다.
    • 예: customerName, totalSum 등
  • 일반적으로 메서드는 무언가 동작하는데 사용되기에 동사로 시작한다.
    • 예: printReport(), addCustomer() 등
