김영한의 자바 입문 - 변수

2026-11-05·2분 읽기

변수

선언

  • 변수를 선언하면 메모리 안에 공간을 확보하여 데이터를 저장할 수 있다.
  • 변수 이름을 통해 해당 메모리 공간에 접근할 수 있다.

초기화

  • 변수를 선언하고, 선언한 변수에 처음으로 값을 저장하는 것을 초기화 라고 한다.
  • 변수를 초기화 하지 않고 사용하면 컴파일 에러가 발생한다.
  • 컴퓨터 메모리는 여러 시스템이 함께 사용하는 공간이다.
  • 변수를 선언하면 메모리상의 어떤 공간을 차지하고 사용한다.
  • 하지만 그 공간에 어떤 값이 있었는지는 아무도 모른다. 따라서 초기화를 하지 않으면 이상한 값이 출력될 수 있다.
  • 이런 문제를 예방하기 위해 java에서는 변수를 초기화하도록 강제한다.
  • 하지만 위 이야기는 지역 변수(Local Variable)에 대해서만 적용되며, 클래스 변수와 인스턴스 변수의 초기화는 java가 자동으로 진행해준다.

타입

자주 사용하는 타입은 볼드 처리.

  • 정수형
    • byte
      • 표현 가능 숫자 범위: -128 ~ 127 (1byte, 2⁸)
      • 표현 길이가 너무 작아서, 파일 전송, 복사 등 파일을 다룰 때를 제외하고는 잘 사용하지 않는다.
    • short
      • 표현 가능 숫자 범위: -32,768 ~ 32,767 (2byte, 2¹⁶)
      • 표현 길이가 너무 작아서 잘 사용하지 않는다.
    • int
      • 표현 가능 숫자 범위: -2,147,483,648 ~ 2,147,483,647 (약 20억) (4byte, 2³²)
      • 자바는 정수에 기본으로 int를 사용한다. 또한 자바는 기본적으로 4byte(int)를 효율적으로 계산하도록 설계되어 있다.
    • long
      • 표현 가능 숫자 범위: -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 (8byte, 2⁶⁴)
      • 다룰 데이터가 20억이 넘을 것 같은 경우 long타입을 사용한다.
  • 실수형
    • double
      • 표현 가능 범위: 대략 -3.4E38 ~ 3.4E38, 7자리 정밀도 (4byte, 2³²)
      • 실수는 고민하지 말고 double을 사용
    • float
      • 표현 가능 범위: 대략 -1.7E308 ~ 1.7E308, 15자리 정밀도 (8byte, 2⁶⁴)
      • 표현 길이와 정밀도가 낮아 잘 사용하지 않는다.
  • 기타
    • boolean (1 byte)
      • 불리언 타입, true, false값만 사용할 수 있다. 참과 거짓을 판단하는 곳에서 사용한다.
      • 조건문에서 자주 사용된다.
    • char (2 byte)
      • 문자 하나를 다룰 때 사용한다. 작은따옴표(')를 사용하여 문자를 감싸서 표현한다.
      • 다만 문자 하나를 표현하는 일은 거의 없고, 문자 하나를 표현하더라도 문자열을 사용하는 것이 더 편리하다.
    • String
      • 첫 글자가 대문자로 시작하는 특별한 타입. 문자열을 다룰 때 사용하며, 큰따옴표(")를 사용하여 문자열을 감싸서 표현한다.
      • 문자를 다룰 때는 문자 하나이든 문자열이든 모두 String을 사용하는 것이 편리하다.

변수 명명 규칙

규칙

  • 변수 이름은 숫자로 시작할 수 없다. (예: 1sum, 2nd)
    • 하지만 숫자를 이름에 포함하는 것은 가능하다. (예: variable1, number2)
  • 이름에는 공백이 들어갈 수 없다.
  • 자바의 예약어를 변수 이름으로 사용할 수 없다. (예: int, class, public)
  • 변수 이름에는 영문자(a-z, A-Z), 숫자(0-9), 달러 기호($), 밑줄(_)만 사용할 수 있다.

관례

  • 변수 이름은 lowerCamelCase를 사용한다. (예: isDone, userAccount)
  • 클래스 이름은 UpperCamelCase를 사용한다. (예: OrderDetail, User)

예외

  • 상수는 모두 대문자를 사용하고, 언더바로 구분한다. (예: USER_LIMIT)
  • 패키지명은 항상 소문자로 작성한다. (예: org.spring.boot)
