김영한의 자바 입문 - 조건문

2026-11-07·2분 읽기

if문

  • java의 if문에는 boolean 또는 Boolean 타입으로 평가되는 표현식이 있어야 하며, 해당 표현식이 true 이면 중괄호 {} 안의 코드를 실행한다.

  • 이전에 다루었던 Swift와는 반대로, java에서 if문의 표현식(Expression)에는 소괄호()가 필수이다.

    • 표현식(Expression)
      • 값을 만들어내는 코드
    • 문장(Statement)
      • 어떤 동작을 수행하는 실행 단위

  • 또한 if문 다음에 실행할 명령이 하나인 경우, 중괄호 { }를 생략할 수 있다.

    • 하지만 권장되지 않는다.
    • 가독성과 유지보수성을 높이기 위해 중괄호를 사용하는 것이 좋다.
    • 예2의 경우, 두번째 줄의 코드는 if문과 관계가 없다.
      • 조건이 true이던 false이던, 두번째 코드는 실행될 것이다.

Switch문

  • if 문은 비교 연산자를 사용할 수 있지만, switch문은 단순히 값이 같은지만 비교한다.

    • switch 키워드 후에 오는 선택자 표현식(selector expression)이 어떤 값과 매치될 때 실행할 코드를 작성할 수 있다.

  • break는 case 내에서 실행중인 코드를 끝내고, switch문을 빠져나가게 하는 역할을 한다.

  • break가 없다면, 일치하는 case 이후 모든 case의 코드들이 순서대로 실행된다.

  • default는 선택자 표현식과 일치하는 case가 없는 경우 실행된다.

    • if문으로 따지면 else와 같다.
    • 필수가 아니며 선택이다.

  • java 14에서 나온 새로운 switch문

    • ->를 사용한다.
    • 선택된 데이터를 반환할 수 있다.

삼항 연산자

  • 단순히 참과 거짓에 따라 처리하는 코드가 달라지는 경우, 삼항 연산자 (조건 연산자로 불리기도 한다)를 통해 코드를 간결하게 작성할 수 있다.
